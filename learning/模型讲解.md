# GenPose2 模型讲解

本文按 **ScoreNet / EnergyNet / ScaleNet** 三部分说明：各自做什么、为何这样设计、优势、结构与输入输出。Score 与 Energy 的原理单独展开并举例。

推理调用见 [`推理过程详解.md`](./推理过程详解.md)；数据格式见 [`数据集格式.md`](./数据集格式.md)。

---

## 0. 总览：三网如何配合

GenPose2（论文 GenPose++）做**实例级 6D 位姿 + 尺寸**估计。不负责分割；输入是 RGB-D、实例 mask、相机内参。同一帧多个实例会 batch 在一起，一次 `inference` 同时给出每位姿与尺寸。

```
实例点云 (+ DINOv2)
      │
      ▼
 ScoreNet   ──► 多样候选位姿（基于分数的扩散采样）
      │
      ▼
 EnergyNet  ──► 能量排序 → 聚合出一个位姿
      │
      ▼
 ScaleNet   ──► size_3d [l,w,h]
```

| 网络 | 类 | 角色一句话 |
|------|-----|------------|
| ScoreNet | `PoseScoreNet` | 学「位姿空间里该往哪走」，从噪声采出候选 |
| EnergyNet | `PoseEnergyNet` | 学「哪个候选更可信」，排序后聚合 |
| ScaleNet | `ScaleNet` | 在已知朝向下估包围盒边长 |

---

## 1. ScoreNet：基于分数（Score-based）的位姿生成

### 1.1 理论铺垫

#### 做什么的

ScoreNet 学习条件分布 \(p(\text{pose} \mid \text{观测})\) 的 **score（分数）**，并用它从噪声中**采样**出多个候选 6D 位姿。

所谓 score，不是分类置信度，而是对数概率密度对变量本身的梯度：

\[
s(x) \;=\; \nabla_x \log p(x)
\]

直观含义：**在位姿空间的某个点 \(x\) 上，密度「上山」的方向与陡峭程度**。沿着 score 走，就会走向高概率区域（更像真值的位姿）。

本仓库默认用 VE-SDE（`sde_mode=ve`）：对真实位姿逐步加噪得到 \(x_t\)，网络在噪声水平 \(t\) 上预测

\[
s_\theta(x_t, t \mid \text{点云/RGB}) \;\approx\; \nabla_{x_t} \log p_t(x_t \mid \text{观测})
\]

推理时从大噪声出发，用 ODE 采样器沿 score 积分去噪（`sampler_mode=ode`），得到干净位姿；对每个实例重复采多次（默认 `eval_repeat_num=50`）。

#### 为什么这样设计

6D 位姿后验经常是**多峰**的：

- 瓶子绕对称轴转 180° 外观几乎一样 → 两个旋转都合理；
- 只看见料盘上沿时，平移/倾角可辨，盘内自转不可辨 → 一片「等高」歧义区；
- 点云残缺时，回归网络容易给出一个「折中错误」解。

若直接回归一个向量 \(\hat{x}\)，等价于假设后验单峰、用均值当答案——多峰时均值往往落在两峰之间，**哪个峰都不对**。

Score-based 生成模型不直接输出「唯一答案」，而是学会整个密度的坡度场，再**采样**：不同随机种子会落到不同峰上，从而保留多解，交给后续 EnergyNet 筛选。

训练（`losses.py` 的 denoising score matching）可简化理解成：

1. 取真值位姿 \(y\)，加噪：\(x = y + \sigma(t)\,z\)，\(z\sim\mathcal{N}(0,I)\)；
2. 理论目标 score ≈ \(-z/\sigma(t)\)（指向真值附近）；
3. 网络预测 \(\hat{s}\)，用加权 MSE 对齐目标。

#### 有什么优势

- **表达多峰**：对称/遮挡时能采出多种合理解，而不是被均值拉偏。
- **与观测条件化**：score 条件于点云特征（+ DINOv2），同一噪声在不同物体上会走向不同位姿。
- **跟踪友好**：可用上一帧位姿作 `init_x`，并缩小起始噪声时间 `T0`，少走弯路。
- **为 Energy 提供候选池**：先「广撒网」，再精排。

代价：要多次采样，比单次回归慢。

#### 举例说明（一维玩具 → 真实位姿）

**一维玩具。** 假设真实「位姿」只能是 \(+1\) 或 \(-1\)（对称双峰），观测不足以区分。

| 方法 | 行为 |
|------|------|
| 直接回归 | 常输出 \(0\)（两峰平均）→ 必错 |
| Score 采样 | 从噪声出发沿 \(\nabla\log p\) 走，约一半样本到 \(+1\)、一半到 \(-1\) → 两个峰都保留 |

**真实 6D 例子。** 桌上一个旋转对称瓶子，点云几乎看不出绕竖直轴转了多少度。

1. ScoreNet 采 50 个候选：平移大多聚在瓶身中心附近；旋转则在「绕竖直轴」上散成一圈（或多个簇）；
2. 这些候选**都还算贴合点云**，只是自转角不同；
3. 若此时直接对 50 个旋转做平均，可能得到一个「奇怪的中间朝向」；所以需要 EnergyNet 先排序/聚类再聚合。

**采样过程心智图（单次）：**

```
t 大（很吵）          t 中等               t → 0（干净）
x ≈ 纯噪声      →   粗略靠近物体附近  →   贴合点云的 6D 位姿
     ↑ score 指示每一步该往哪挪一点（ODE 积分）
```

### 1.2 模型结构

Score 路径包在 `GFObjectPose`（`agent_type=score`）里：

```
ROI RGB ──► DINOv2 (冻结, pointwise) ──┐
                                       ├─► PointNet++ Fus ──► pts_feat [B,1024]
实例点云 [B,1024,3] ───────────────────┘
                                              │
                    sampled_pose [B,9], t [B,1]
                                              │
                                              ▼
                              ┌───────────────────────────┐
                              │ PoseScoreNet              │
                              │  t_encoder  → 128         │
                              │  pose_encoder → 256       │
                              │  concat(pts,t,pose[,rgb]) │
                              │  头: Rx / Ry / T 各 3 维  │
                              │  输出 / σ(t) → score      │
                              └───────────────────────────┘
                                              │
                                              ▼
                              ODE/PC 采样器循环调用 score
                                              │
                                              ▼
                              候选位姿 [B, K, 9]  (K=50)
```

| 子模块 | 作用 |
|--------|------|
| DINOv2 ViT-S/14 | ROI 外观特征；`pointwise` 时按点取 patch 特征拼到点上 |
| PointNet++ | 几何（+外观）→ 全局 `pts_feat` |
| `t_encoder` | Gaussian Fourier 编码噪声时间 |
| `pose_encoder` | 编码当前噪声位姿 |
| 回归头 `Rx_Ry_and_T` | 6D 旋转（两列）+ 平移；比欧拉角连续 |
| 采样器 | `cond_ode_sampler`；结束时把平移加回 `pts_center` |

位姿表示默认 `pose_mode=rot_matrix`，维度 **9 = 6（旋转）+ 3（平移）**。

### 1.3 输入输出

**网络单步（预测 score）**

| 输入 | 形状 | 含义 |
|------|------|------|
| `pts_feat` | `[B, 1024]` | 点云全局特征 |
| `rgb_feat` | 可选 | `dino=global` 时使用；`pointwise` 已融进编码器 |
| `sampled_pose` | `[B, 9]` | 当前噪声/中间位姿 |
| `t` | `[B, 1]` | 扩散时间 / 噪声水平 |

| 输出 | 形状 | 含义 |
|------|------|------|
| `score` | `[B, 9]` | 位姿空间中的分数场（已按 \(\sigma(t)\) 归一） |

**推理级（`pred_func`）**

| 输出 | 形状 | 含义 |
|------|------|------|
| 候选位姿 | `[B, K, 9]` | \(K\) 次独立采样结果（平移已在相机系） |
| 旁路特征 | `pts_feat` / `rgb_feat` | 留给 ScaleNet 复用 |

代码：`networks/gf_algorithms/scorenet.py`、`networks/gf_algorithms/samplers.py`、`networks/posenet_agent.py` → `pred_func`。

## 2. EnergyNet：基于能量（Energy-based）的候选筛选

### 2.1 理论铺垫

#### 做什么的

EnergyNet 给 ScoreNet 采出的每个候选位姿打一个（或一对）**能量分**，用来排序：谁更像真值、谁该丢掉。然后对高分子集做四元数平均（可选 DBSCAN 聚主峰），聚合成**一个**位姿。

经典能量模型把密度写成：

\[
p(x) \;\propto\; \exp\big(-E(x)\big)
\]

即：**能量越低，概率越高**。本仓库里能量由网络输出 \(f_\theta\) / \(s_\theta\) 构造（`energy_mode`），默认 `IP`（内积）：

```text
s_theta ≈ score   (s_theta_mode='score' 时 s = f/σ)
energy_rot   = ⟨pose_rot,   s_rot⟩
energy_trans = ⟨pose_trans, s_trans⟩
```

推理排序用 `sort_poses_by_energy`：**按能量从高到低排**（本实现约定「能量更高 → 更优先保留」；训练时用 ranking loss 让更接近真值的样本能量更高）。可把它理解成「可信度分数」，名字叫 energy，但**排序方向以代码为准：越大越优先**。

旋转、平移可解耦排序，再按 `retain_ratio`（默认 0.4）丢掉后 60% 离群样本。

#### 为什么这样设计

Score 采样解决了「能覆盖多峰」，但引出新问题：

1. **样本质量不齐**：50 个里有贴合很好的，也有未收敛的、落到次峰的；
2. **简单平均会毁主峰**：双峰各一半时，平均旋转往往两边都不像；
3. **需要可学习的排序**，而不是手写「点云重投影误差」（对称时误差也可能都很低）。

EnergyNet 与 ScoreNet **结构同构**，但训练目标不同：学一个与位姿质量一致的标量场。还可令 \(s = \nabla_{\text{pose}} E\)（对 pose 反传），使能量与 score 在数学上相容（`forward(..., return_item='score')`）。

直觉分工：

| | ScoreNet | EnergyNet |
|--|----------|-----------|
| 像什么 | 「地图上的风向」：往哪走密度更高 | 「海拔/可信度」：终点好不好 |
| 产出 | 许多候选轨迹终点 | 每个终点一个分，再筛选 |

#### 有什么优势

- **抗离群**：差样本被排到后面并裁掉，再平均更稳。
- **处理对称多峰**：可先按能量保留主簇，再 DBSCAN（`clustering`）只在最大簇内平均，避免两峰对拉。
- **旋转/平移分开打分**：平移准但旋转差（或反过来）时不会被一个标量糊弄过去。
- **可关掉**：无 Energy 权重时，代码仍可用均匀权重聚合，便于消融。

#### 举例说明

**例子 A：对称瓶子，Score 给出两簇旋转。**

```
候选旋转（俯视自转角）:
  簇 A（≈ 0°）:  22 个样本，能量偏高
  簇 B（≈180°）: 20 个样本，能量略低
  离群:           8 个样本，能量很低

步骤:
  1) 按能量降序，retain_ratio=0.4 → 留下约 20 个高分（多半来自簇 A）
  2) 可选 DBSCAN：最大簇 = A
  3) 对 A 做四元数平均；平移对高分样本取均值
结果: 稳定落在一个对称等价解上，而不是 A、B 的「中间朝向」
```

**例子 B：为何需要能量，而不是只信 Score。**

Score 保证「沿着坡能走到某个峰」，但不保证「你停下来的那个峰是任务想要的那个」。例如跟踪时上一帧在峰 A，当前帧仍可能有样本跳到峰 B（对称跳变）。Energy + 聚合（再配合跟踪 `init_x`）用来压住这种跳变。

**例子 C：L2 能量模式的直观（`energy_mode=L2`）。**

\[
E = -\tfrac12 \|s_\theta\|^2
\]

在概率峰附近，score 接近 0 → \(E\) 接近 0（相对更大）；在远离高密度区，\(\|s\|\) 往往更大 → \(E\) 更负。于是「更大的 \(E\)」仍对应「更像峰顶」，与降序保留一致。

默认 `IP` 模式用 \(\langle x, s\rangle\) 等形式，训练用 pair-wise ranking loss（`networks/reward.py`）直接优化「好样本能量高于差样本」，不必死记公式符号，记住：**排序时能量高者优先**。

### 2.2 模型结构

```
pts_feat, (rgb_feat), sampled_pose, t
              │
              ▼
┌─────────────────────────────────────┐
│ PoseEnergyNet（结构几乎同 ScoreNet） │
│  t_encoder / pose_encoder / 三头    │
│  → f_theta → s_theta                │
│  → energy（L2 / DAE / IP）          │
└─────────────────────────────────────┘
              │
              ▼
     energy [B*K, 2]  (rot 分, trans 分)
              │
              ▼
     sort → retain → 四元数平均 / DBSCAN
              │
              ▼
     聚合位姿 [B, 4, 4]
```

聚合在 `runners/infer.py` → `_aggregate_pose`：

1. `sort_poses_by_energy`（高→低）；
2. 保留前 `retain_ratio * K`；
3. 旋转 → 四元数 → `average_quaternion_batch`；可选 DBSCAN；
4. 平移取均值 → 拼 \(4\times4\)。

### 2.3 输入输出

| 输入 | 形状 | 含义 |
|------|------|------|
| `pts_feat` | `[B, 1024]` | 与 Score 同源的观测特征 |
| `rgb_feat` | 可选 | 同 Score |
| `sampled_pose` / `pose_samples` | `[B, K, 9]` | ScoreNet 的候选 |
| `t` | 标量或张量 | 评能量时的噪声时间（测试时常固定/约定） |

| 输出 | 形状 | 含义 |
|------|------|------|
| `energy` | `[B, K, 2]` | 每候选的旋转分、平移分；**越大越优先** |
| 聚合位姿 | `[B, 4, 4]` | 排序聚合后的刚体变换 |

代码：`networks/gf_algorithms/energynet.py`、`networks/reward.py` → `sort_poses_by_energy`、`PoseNet.get_energy`。

## 3. ScaleNet：已知朝向下的尺寸回归

### 3.1 理论铺垫

#### 做什么的

在 Score+Energy 已经给出旋转（物体坐标轴）之后，ScaleNet 估计轴对齐包围盒边长 \(\mathrm{size\_3d}=[l,w,h]\)。

它不参与扩散，不做多假设采样，就是一个条件于点云特征与轴向的回归头。

#### 为什么这样设计

- **姿态与尺度统计特性不同**：姿态在 \(SO(3)\times\mathbb{R}^3\) 上多峰、需生成模型；尺寸在 \(\mathbb{R}^3_+\) 上通常更接近单峰回归。
- **尺度依赖轴向**：同一堆点云，轴转 90° 后 \(l,w\) 会互换；必须先定 `axes` 再估长度。
- **监督更干净**：GT 来自 `bbox_side_len`，与对称旋转歧义相对解耦（对称时姿态难标，尺寸往往仍稳定）。
- **可替换**：无 Scale 权重时，可用物体坐标系下点云的 AABB 当尺寸（`_inference_scale` 里的回退分支）。

#### 有什么优势

- 小网、快，推理负担远小于 Score/Energy。
- 与姿态解耦，Scale 坏了不一定毁旋转，反之亦然。
- 输出可直接画 3D 框、给抓取/摆放用。

局限：轴向错了，尺寸会对错轴；点云极残缺时厚度方向会飘（料盘边缘场景见 [`料盘边缘场景训练.md`](./料盘边缘场景训练.md)）。

#### 举例说明

料架上一个圆盘，Score/Energy 给出盘面法向（\(z\) 轴），点云主要是上沿弧线：

- ScaleNet 吃 `pts_feat` + 编码后的 `axes`，输出例如 `[0.30, 0.30, 0.02]`（直径、直径、厚度）；
- 若轴向绕错 90°，可能把厚度估到错误轴上 → 框「立起来」——说明尺寸头强依赖前面姿态质量。

### 3.2 模型结构

```
axes [B,3,3] ──► encode_axes (sin/cos) ──► MLP → 256
pts_feat [B,1024] (+ rgb_feat) ──────────────┐
                                             ├─► MLP → length [B,3]
axes_feat ───────────────────────────────────┘
```

实现：`networks/scalenet.py`。`encode_axes` 把旋转矩阵元素做成傅里叶式位置编码，再与点云特征融合。当前 `pred_scale_func` **只回归长度**，返回的旋转即传入的 `axes`（不再改朝向）。

### 3.3 输入输出

| 输入 | 形状 | 含义 |
|------|------|------|
| `pts_feat` | `[B, D]` | 通常复用 Score 阶段特征 |
| `rgb_feat` | 可选 | `dino=global` 时 |
| `axes` | `[B, 3, 3]` | Energy 聚合后的旋转矩阵 |

| 输出 | 形状 | 含义 |
|------|------|------|
| `length` | `[B, 3]` | `[l, w, h]`，与 `axes` 各轴对应 |

损失：对 GT 边长的 MSE（实现里乘了大系数做加权）。

## 5. 一张图串起 Score 与 Energy

```
位姿空间（示意）

        峰 A ●●●●          峰 B ●●●
              ▲                 ▲
              │ score 场        │
         （箭头指向峰顶）

Score 采样:  从四周噪声 → 爬到 A 或 B（或偶发离群）
Energy 打分: 给每个落点海拔/可信度 → 留下更高者
聚合:        只在留下的点上平均 → 一个最终位姿
Scale:       拿最终朝向 + 点云特征 → [l,w,h]
```

**一句话对照：**

- **Score（分数）**：\(\nabla_x\log p\) ——「往哪走更像真值」→ 用来**生成**候选；
- **Energy（能量）**：由 \(s_\theta\) 构造的排序标量 ——「停在这儿好不好」→ 用来**筛选**候选；
- **Scale**：普通回归 ——「框有多大」。
