# 视觉为主、深度为辅的优化方案（结构改动版）

相关阅读：[`视觉为主深度辅助的优化方案.md`](./视觉为主深度辅助的优化方案.md)、[`模型讲解.md`](./模型讲解.md)、[`料盘边缘场景训练.md`](./料盘边缘场景训练.md)。

本文侧重 **三项网络结构改动**（注意力融合、热启动采样、门控加权），与上一份方案互补。

---

## 1. 问题背景

在电子料盘抓取等工业场景中，深度相机常因 **反光、吸光、工作距离偏远** 等原因，返回的 3D 点云极其稀疏、嘈杂；而料盘的 **RGB 特征**（规则边缘、固定孔位、标志性外观）往往更稳定可靠。

### 1.1 当前 GenPose2 架构痛点

原架构里，DINOv2 图像特征通过 `pointwise`（按点投射）融合到 3D 点云上，再经 PointNet++ 提取全局几何特征 `pts_feat`：

```
ROI RGB ──► DINOv2 (pointwise) ──┐
                                 ├─► PointNet++ ──► pts_feat
稀疏点云 ────────────────────────┘
```

**痛点**：深度极稀疏时，PointNet++ 做 Ball Query / KNN 邻域聚合会因邻域点不足而失效，高维 RGB 特征也无法被有效提取与融合。

### 1.2 目标

实现 **「以视觉为主，深度为辅」** 的位姿估计：视觉主导假设，深度只提供尺度 / 距离等弱约束。

---

## 2. 三项核心结构修改

### 2.1 修改一：解耦 RGB 与 Depth，引入交叉注意力融合

打破「先投影再 PointNet++」，改为 **双支路解耦提取 + 后期自适应融合**：

```
ROI RGB ──────► DINOv2 (Global / Patch) ──┐
                                          ├─► Cross-Attention ──► F_fused
稀疏点云 ─────► 轻量 PointNet++ / Point-MLP ─┘
```

#### 具体改法

| 支路 | 做法 |
|------|------|
| **RGB 强特征** | DINOv2 提取 ROI 全局特征（如 \(1\times 384\)）或 Patch 特征，作为最可靠的骨干先验 |
| **稀疏 Depth** | 降低 PointNet++ 层数，或改用简单 Point-MLP；对少量 3D 坐标做位置编码，只提取基本空间尺度特征 |
| **Cross-Attention** | RGB 作 **Query**；稀疏深度特征作 **Key / Value** |

**原理**：以视觉外观为主导，去稀疏深度中「查询」三维尺度与距离。深度空洞处注意力权重可自然趋近 0，从而屏蔽深度噪声。

---

### 2.2 修改二：视觉引导的热启动扩散采样（Warm-start）

原 ScoreNet 推理从纯高斯噪声出发，经多步 PF-ODE 积分采样 6D 位姿。深度很差时，在宽广去噪空间中易迷失方向。

#### 具体改法

1. **2D 辅助回归头**  
   在 DINOv2 的 \(F_{rgb}\) 后挂轻量 MLP，直接预测图像上的 2D 中心 \((u, v)\) 与粗略 2D 旋转角 \(\theta\)。

2. **深度反投影**  
   用少量可靠深度，将 2D 中心粗略反投影到 3D，得到方向大致正确的初始位姿 \(p_{\mathrm{init}}\)。

3. **窄窗口扩散（参考 Tracking）**  
   不必从 \(t=1\) 纯噪声起步；将起始时间设为较小值（如 \(T_0 = 0.2\) 或 \(0.3\)），以 \(p_{\mathrm{init}}\) 为起点做反向 ODE 去噪。

**优势**：ScoreNet 主要做「修正 / 微调」，大幅降低对完整深度几何的依赖。

---

### 2.3 修改三：增强 Score / Energy 中的 RGB 权重

原 PoseScoreNet / PoseEnergyNet 输入端是直接拼接：

\[
\mathrm{concat}(F_O,\, F_p,\, F_t)
\]

#### 具体改法

1. 用解耦增强后的 \(F_{\mathrm{fused}}\) 替换原本的 \(F_O\)。
2. 在 MLP 降维与拼接前，为 RGB 引入残差或门控：

\[
F_{\mathrm{conditioned}}
=
W_{\mathrm{rgb}} \cdot F_{\mathrm{rgb}}
+
\sigma(W_d \cdot F_{\mathrm{depth}}) \cdot F_{\mathrm{depth}}
\]

训练中若深度不可靠，门控 \(\sigma(\cdot)\) 可趋近 0，网络近似退化为 **主要依赖 RGB** 做位姿生成。

---

## 3. 落地行动建议

若已有料盘 3D CAD（如 `process_cad.py` 相关管线），可按以下步骤推进「视觉为主」新网络：

| 步骤 | 内容 |
|------|------|
| **合成数据升级** | 渲染时对 Depth 做大比例 Random Dropout / 加噪，模拟现场稀疏深度；RGB 保持清晰 |
| **特征加载改造** | 在 `networks/posenet.py` 的 `GFObjectPose` 中，将 `dino=pointwise` 改为 `dino=global`，或接入自定义解耦 Fusion 模块 |
| **可选实现** | 用 PyTorch 实现 Cross-Attention Fusion Layer，替换原 PointNet++ 融合部分 |

## 5. 一句话结论

解耦 RGB / Depth → 视觉作 Query 的交叉注意力融合；用 2D 回归 + 可靠深度做热启动；Score / Energy 侧用门控抬高 RGB 权重——三步一起，才能在深度「几乎看不见」时仍稳定估出料盘 6D 位姿。
