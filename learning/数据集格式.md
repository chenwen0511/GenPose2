# GenPose2 数据集格式

## 1. 数据需求

GenPose2 训练时使用的是 Omni6DPose 的合成训练集 SOPE。每帧需要：

- RGB 彩色图
- 深度图
- 实例分割 Mask
- 相机内参
- 每个实例的类别、尺寸、旋转、平移、对称性等标注

运行训练时，`--data_path` 指向：

```
D:/datasets/Omni6DPose/SOPE
```

不是 Omni6DPose 总目录，也不是某个 `train` 目录。

代码会按下面的形式查找数据：

```
SOPE/*/train/...
SOPE/*/test/...
```

其中：

- `train/` 用于训练。
- `test/` 同时被代码用于 validation 和 test。
- 当前代码没有单独读取 `val/` 文件夹。

## 3. 同一帧文件命名规则

四个文件必须共用完全相同的前缀：

```
000123_color.png
000123_depth.exr
000123_mask.exr
000123_meta.json
```

## 4. 每种文件的内容与格式

### `*_color.png`

RGB 彩色图。

要求：

- PNG 格式。
- 通常是 8-bit、3 通道。
- RGB、深度、Mask 必须具有相同的宽高和像素对齐关系。
- OpenCV/cutoop 负责加载，训练时会裁剪到 224×224。
- 训练代码使用 ImageNet 均值和方差做归一化。

建议：

| 项目 | 值 |
|------|-----|
| 数据类型 | `uint8` |
| 形状 | `H × W × 3` |
| 值域 | `0～255` |

原始图不需要提前缩放到 224×224。

### `*_depth.exr`

每像素深度图。

要求：

- OpenEXR 格式。
- 单通道浮点深度。
- 无效深度设置为 0。
- 与 RGB、Mask 像素级对齐。
- 深度单位必须与 `meta.json` 里的 `translation`、`bbox_side_len` 保持一致。

建议统一使用米：

| 项目 | 值 |
|------|-----|
| 数据类型 | `float32` |
| 形状 | `H × W` |
| 单位 | 米 |
| 无效值 | `0` |

例如：`0.62` 表示距离相机 0.62 米。

加载器会从 Mask 内的有效深度生成点云，经过裁剪后有效点少于 50 个的实例会被跳过。因此物体 Mask 内必须有足够的非零深度。

如果启动训练时添加：

```bash
--perfect_depth
```

代码会改读：

```
*_depth_syn.exr
```

默认不加这个参数时，只需要 `*_depth.exr`。

### `*_mask.exr`

实例分割图，不是普通的二值概率图。

格式建议：

| 像素值 | 含义 |
|--------|------|
| 形状 | `H × W` |
| `0` | 背景 |
| `1` | 第一个物体 |
| `2` | 第二个物体 |
| `3` | 第三个物体 |
| ... | ... |

例如：

```
0 = 背景
1 = 杯子实例
2 = 瓶子实例
3 = 盒子实例
```

关键要求：

- `meta.json` 中每个物体的 `mask_id` 必须等于 Mask 图里的像素值。
- 同一个物体的所有前景像素使用同一个整数 ID。
- 不同实例不能共用相同 ID。
- Mask 与 RGB、深度分辨率一致。
- Mask 内需要存在足够有效深度。

虽然文件扩展名是 EXR，但表达的是离散实例 ID，读取后不能经过会改变 ID 的平滑插值。

### `*_meta.json`

这是每帧最重要的标注文件，至少包含：

- 相机内参
- 相机信息
- 当前帧中全部可见物体
- 每个物体的实例 ID
- Mask ID
- 类别名称和类别编号
- 3D 尺寸
- 旋转四元数
- 平移
- 标注是否有效

结构示意：

```json
{
  "camera": {
    "intrinsics": {
      "fx": 600.0,
      "fy": 600.0,
      "cx": 320.0,
      "cy": 240.0,
      "width": 640,
      "height": 480
    },
    "quaternion_wxyz": [1.0, 0.0, 0.0, 0.0],
    "translation": [0.0, 0.0, 0.0],
    "scene_obj_path": "",
    "background_image_path": "",
    "background_depth_path": "",
    "distances": [],
    "kind": ""
  },
  "objects": [
    {
      "mask_id": 1,
      "meta": {
        "oid": "my_dataset-bottle-000001",
        "class_name": "bottle",
        "class_label": 0,
        "instance_path": "",
        "scale": [1.0, 1.0, 1.0],
        "is_background": false,
        "bbox_side_len": [0.08, 0.08, 0.22]
      },
      "quaternion_wxyz": [1.0, 0.0, 0.0, 0.0],
      "translation": [0.02, -0.01, 0.65],
      "is_valid": true,
      "id": 1,
      "material": [],
      "world_quaternion_wxyz": [1.0, 0.0, 0.0, 0.0],
      "world_translation": [0.0, 0.0, 0.0]
    }
  ],
  "scene_dataset": "Omni6DPose",
  "env_param": {},
  "face_up": true,
  "concentrated": false,
  "comments": "",
  "runtime_seed": 0,
  "baseline_dis": 0,
  "emitter_dist_l": 0
}
```

注意：这是依据 cutoop 数据类给出的结构示意。最稳妥的做法是从官方 SOPE 的真实 `meta.json` 复制模板，再替换自己的值，因为 cutoop 某些版本对辅助字段也有构造要求。

| 字段 | 内容 |
|------|------|
| `camera.intrinsics.fx/fy` | 焦距，单位为像素 |
| `camera.intrinsics.cx/cy` | 主点坐标 |
| `width/height` | 标定对应的图像尺寸 |
| `objects` | 当前帧中所有物体 |
| `mask_id` | 物体在 `mask.exr` 中对应的整数值 |
| `oid` | 全局唯一实例名称，必须能在 `obj_meta.json` 中找到 |
| `class_name` | 类别名 |
| `class_label` | 类别编号 |
| `bbox_side_len` | 物体三维包围盒边长 `[x,y,z]` |
| `quaternion_wxyz` | 相机坐标系下旋转，顺序固定为 `[w,x,y,z]` |
| `translation` | 相机坐标系下平移 `[x,y,z]` |
| `is_valid` | 是否把该物体作为有效训练样本 |

## 5. 全局 `obj_meta.json`

官方 SOPE 的 `Meta/obj_meta.json` 需要复制到当前项目：

```
D:/AIAgent/work/RobotGames/GenPose2/GenPose2/configs/obj_meta.json
```

最终项目目录应为：

```
GenPose2/
└── configs/
    ├── config.py
    ├── obj_meta.json
    └── real_obj_meta.json
```

- 训练 SOPE 使用：`configs/obj_meta.json`
- 评估 ROPE 真实数据使用：`configs/real_obj_meta.json`

`obj_meta.json` 负责描述整个数据集的：

- 类别列表和类别名称
- 所有物体实例的 `oid`
- 物体实际尺寸
- 对称性
- 物体标签和其他全局属性

其中每个 `meta.json` 的：

```json
"oid": "my_dataset-bottle-000001"
```

必须能在 `obj_meta.json` 的实例字典中找到，否则加载器会直接跳过该样本。

训练还会从这里取得对称性：

```
symmetry.any
symmetry.x
symmetry.y
symmetry.z
```

各轴允许的值是：`none` / `any` / `half` / `quarter`。

例如旋转对称瓶子可以表示为类似：

```json
{
  "symmetry": {
    "any": false,
    "x": "none",
    "y": "none",
    "z": "any"
  }
}
```

具体 JSON 外层结构建议直接以官方 `obj_meta.json` 为模板，不要自行猜测，因为加载器依赖 `cutoop.obj_meta.ObjectMetaData` 反序列化。

