# 交叉注意力深度融合（Cross-Attention Fusion）

在多模态融合中，**交叉注意力**的核心是：用一种模态作为 Query，去另一种模态中检索并聚合相关特征。

本文针对 GenPose2 的料盘 6D 位姿估计场景，约定 **RGB 为主、深度为辅**：视觉特征充当 Query，稀疏点云提供 Key / Value。直观理解：可靠的 RGB 像买家拿着清单，去不完整的深度货架上挑选最匹配的几何信息。

相关文档：[深度数据大量丢失：原因与补救](./如何补救.md)

---

## 1. 与现有融合方式的对比

当前推理默认 `cfg.dino = 'pointwise'`（见 `networks/posenet.py` 的 `extract_pts_feature`）：

1. DINOv2 输出 ROI 的 patch 特征。
2. 按点云像素坐标 `roi_xs / 14`、`roi_ys / 14` 从 patch 网格 **gather** 对应视觉特征。
3. 将 `[pts, rgb_feat]` 拼接后送入 `Pointnet2ClsMSGFus`。

这是 **点对点强制对齐**：每个 3D 点只能看到投影落点上的那一个 RGB patch。深度缺失、飞点、投影错位时，错误几何会原样进入编码器。

交叉注意力改为 **视觉提问、深度应答**：不要求每个点都有可靠深度，也不要求 RGB 与点云预先逐点对齐。

---

## 2. Query / Key / Value 角色

自注意力中 Q、K、V 来自同一输入；交叉注意力中它们分属不同模态。以视觉主导时：

| 符号 | 来源 | 张量角色 | 物理含义 |
|------|------|----------|----------|
| **Q** | RGB（DINOv2 patch） | 查询 | 「这个图像块对应的 3D 深度 / 几何是什么？」 |
| **K** | 稀疏点云（PointNet++ 逐点特征） | 索引 | 「这些 3D 点各自对应怎样的几何描述」 |
| **V** | 同上 | 内容 | 实际要聚合的三维几何特征 |

---

## 3. 前向计算

### 3.1 线性投影与维度对齐

DINOv2（如 ViT-S/14，维度 384）与 PointNet++ 逐点特征（如 256 维）通道不同，先用可学习矩阵映射到同一隐层维度 $d$：

$$
Q = F_{\mathrm{rgb}} W_Q,\quad
K = F_{\mathrm{depth}} W_K,\quad
V = F_{\mathrm{depth}} W_V
$$

### 3.2 注意力权重（相似度匹配）

用 $Q$ 与 $K$ 的内积衡量「每个 2D patch」与「每个 3D 点」的关联：

$$
A = \mathrm{softmax}\left(\frac{Q K^{\top}}{\sqrt{d}}\right)
$$

对稀疏 / 噪声深度的作用：无效点、飞点在 $K$ 上与可靠 RGB 特征几乎无关，softmax 后权重趋近于 0；边缘、孔位等视觉与几何一致的区域权重高。相当于在融合阶段做一次可学习的去噪筛选。

### 3.3 加权聚合与残差

$$
F_{\mathrm{fused}} = A V
$$

再经 MLP 投回 RGB 维度，并与原始视觉特征残差相加：

$$
\mathrm{Output} = \mathrm{MLP}(F_{\mathrm{fused}}) + F_{\mathrm{rgb}}
$$

这样 2D 特征被注入经过筛选的 3D 几何；深度完全失效时，$A$ 趋于均匀，残差使网络近似退化为纯 RGB 推理，而不是因点云为空而崩溃。

---

## 4. 相对 pointwise 投影的三点优势

1. **去噪**：由可靠 RGB（$Q$）筛选点云（$K$），金属反光、吸光、飞点因无法与图像语义匹配而被压低权重，而不是被一刀切拼进 PointNet++。
2. **不必逐点对齐**：RGB 是规则 2D 栅格，点云是不规则 3D 点。相似度矩阵让网络自己学习「图像上的某块区域」对应「空间中的哪些激光点」，无需 `gather` 投影。
3. **视觉主导、深度托底**：某一视角深度全无时，残差连接使输出接近纯视觉特征，可继续用透视与表观尺度估计粗深度；现有 PointNet++ 路径在点数不足时则明显退化。

## 5. 参考实现

建议新建 `networks/attention_fusion.py`（也可并入 `networks/posenet.py`）。输入为 DINOv2 的 patch 序列与 PointNet++ **Max-Pooling 之前**的逐点特征。

```python
import math
import torch
import torch.nn as nn


class RobustCrossAttentionFusion(nn.Module):
    def __init__(self, rgb_dim=384, depth_dim=256, embed_dim=256):
        """
        :param rgb_dim: RGB 特征维度（DINOv2-S 为 384）
        :param depth_dim: 点云逐点特征维度（PointNet++ 中间层，如 256）
        :param embed_dim: Q / K / V 统一隐层维度
        """
        super().__init__()
        self.embed_dim = embed_dim

        self.q_proj = nn.Linear(rgb_dim, embed_dim)
        self.k_proj = nn.Linear(depth_dim, embed_dim)
        self.v_proj = nn.Linear(depth_dim, embed_dim)

        self.out_proj = nn.Sequential(
            nn.Linear(embed_dim, embed_dim),
            nn.GELU(),
            nn.Linear(embed_dim, rgb_dim),
        )

        self.norm_rgb = nn.LayerNorm(rgb_dim)
        self.norm_depth = nn.LayerNorm(depth_dim)

    def forward(self, rgb_feat, depth_feat):
        """
        :param rgb_feat:   [B, N_rgb, rgb_dim]   DINOv2 patch 特征（或 N_rgb=1 的全局特征）
        :param depth_feat: [B, N_pts, depth_dim] 逐点特征，如 N_pts=1024
        :return: out [B, N_rgb, rgb_dim], attn_weights [B, N_rgb, N_pts]
        """
        rgb_norm = self.norm_rgb(rgb_feat)
        depth_norm = self.norm_depth(depth_feat)

        Q = self.q_proj(rgb_norm)      # [B, N_rgb, embed_dim]
        K = self.k_proj(depth_norm)    # [B, N_pts, embed_dim]
        V = self.v_proj(depth_norm)    # [B, N_pts, embed_dim]

        scores = torch.bmm(Q, K.transpose(1, 2)) / math.sqrt(self.embed_dim)
        attn_weights = torch.softmax(scores, dim=-1)  # [B, N_rgb, N_pts]

        fused_depth = torch.bmm(attn_weights, V)      # [B, N_rgb, embed_dim]
        out = self.out_proj(fused_depth) + rgb_feat   # 视觉主导残差

        return out, attn_weights
```

## 6. 接入 `GFObjectPose` 的改造要点

接入点在 `networks/posenet.py` 的 `GFObjectPose`。与现有 `dino=pointwise` 路径对比，需要改四件事：

| 步骤 | 现有做法 | 交叉注意力做法 |
|------|----------|----------------|
| RGB | `get_intermediate_layers` 后按点 `gather` 成 `[B, N_pts, 384]` | 保留完整 patch 序列，如 `[B, 256, 384]`，作为 $Q$ |
| 点云 | 与 RGB 拼接后进 `Pointnet2ClsMSGFus`，输出全局向量 | 取 Max-Pooling **之前**的逐点特征，如 `[B, 1024, 256]`，作为 $K/V$ |
| 融合 | 点级 concat | `RobustCrossAttentionFusion(rgb_feat, depth_feat)` |
| 条件向量 | 点云全局特征（可选再拼 DINO global） | 对融合结果在 patch 维做 Max / Avg Pool，得到 `[B, 384]` 的 $F_{\mathrm{fused}}$，再喂给 ScoreNet / EnergyNet |

注意：当前 `PoseScoreNet` / `PoseEnergyNet` 仅在 `cfg.dino == 'global'` 时接收 `dino_dim + embedding_dim` 条件。接入交叉注意力后，需要把 $F_{\mathrm{fused}}$（及原有的 `encode_axes(roi_center_dir)` 等）接到这两个头的条件通道，而不是继续走 `concat(pts, t, pose)` 式的粗拼接。

DINOv2-S/14 的 patch 数取决于 ROI 分辨率；上表中的 `256` 仅为示例，实现时以 `get_intermediate_layers` 的实际 `N_rgb` 为准。
