# 视觉为主、深度为辅的优化方案

相关阅读：[`模型讲解.md`](./模型讲解.md)、[`料盘边缘场景训练.md`](./料盘边缘场景训练.md)、[`推理过程详解.md`](./推理过程详解.md)。

---

## 1. 问题背景

### 1.1 现场现象

电子料盘货架场景下：

- **深度传感器返回有效点很少**：实例 mask 内深度空洞多、飞点多，或仅剩稀疏边缘点。
- **RGB 视觉数据相对可靠**：盘面纹理、槽位结构、边缘轮廓、指示灯等外观线索稳定可读。
- 业务目标仍是估计料盘的 **位置（平移）与姿态（旋转）**，供后续抓取 / 对齐使用。

一句话：**几何不可靠、外观可靠**——与 GenPose2 默认「点云条件为主」的假设冲突。

### 1.2 当前 GenPose2 条件化方式（为何会吃亏）

本仓库推理主干仍是 **点云条件的扩散位姿估计**（见 `networks/posenet.py`）：

```
ROI RGB ──► DINOv2（冻结）──┐
                            ├─► PointNet++ ──► pts_feat
实例点云 xyz ───────────────┘
                                 │
                                 ▼
                    Score / Energy（条件于 pts_feat）
                                 │
                                 ▼
                    平移再加回 pts_center → 6D 位姿
```

即使开启 `dino=pointwise`，外观特征也只是 **按点拼到 xyz 上**，再经 PointNet++ 汇成全局 `pts_feat`。因此：

| 环节 | 深度差时的后果 |
|------|----------------|
| 点云采样 / 中心 `pts_center` | 中心漂移 → **平移整体偏**（尤其光轴方向 \(T_z\)） |
| PointNet++ 集合抽象 | 稀疏/噪声点主导几何 → **旋转也可能被带偏** |
| DINOv2 贴附 | 外观被「稀释」，无法在差深度时接管决策 |
| Score / Energy | 条件分布学的是「坏几何下的峰」，再多样本也难救 |

结论：瓶颈不在扩散头本身，而在 **观测条件编码器把权力交给了不可靠的深度点云**。

### 1.3 目标表述

在尽量保留 GenPose2「多假设采样 + Energy 聚合」优势的前提下，把条件化改成：

> **以 RGB 视觉为主定姿态假设；深度按置信度做尺度 / 距离 / 歧义消解的弱约束。**

---

## 2. 设计原则

1. **不先扔掉扩散**：密排、遮挡、对称料盘仍有多峰问题，Score + Energy 仍有价值。
2. **升格 RGB 通路**：外观不能只当 PointNet 的附加通道，应有独立、可加权的条件向量（或 token）。
3. **深度降级为辅信号**：带置信度；空洞多时主动降权，而不是硬凑 1024 个不可靠点。
4. **平移与旋转解耦对待**：平面位置 / 朝向更靠 RGB；沿光轴距离更靠少量可靠深度（或已知层高）。
5. **改动可分阶段验证**：先诊断与加权，再双分支结构，最后才考虑解冻 DINO。

---

## 3. 解决方案

### 3.1 方案 A（首选）：双分支条件 — Vision Primary + Depth Auxiliary

将单一 `pts_feat` 拆成可融合的两路：

| 分支 | 输入 | 作用 | 深度差时 |
|------|------|------|----------|
| **V（主）** | ROI RGB → DINOv2（+ 可选轻量可训 adapter / LoRA） | 朝向、实例外观、槽位纹理对齐 | 权重升高 |
| **D（辅）** | 稀疏点云或深度图编码 | 距离、粗尺度、前后关系 | 权重降低 |

融合示例：

\[
\text{feat} = \alpha\, V + (1-\alpha)\, D
\]

或对 V/D token 做 cross-attention。其中 \(\alpha\)（或等价门控）由 **深度置信度** 预测：有效点少、方差大、覆盖率低 → \(\alpha \uparrow\)。

ScoreNet / EnergyNet 头可基本保留，只更换条件特征来源。

### 3.2 方案 B：深度置信度与稀疏感知（可与 A 叠加，适合先做）

不要把稀疏深度当成稠密几何：

- **置信度特征**：mask 内有效点数、深度方差、覆盖率、飞点比例 → `depth_conf ∈ [0,1]`。
- **点过滤**：只保留高置信深度点；宁少勿滥，避免空洞处填噪声凑满 `num_points`。
- **平移残差化**：
  - 粗平移：实例框 / mask 中心反投影 + 少量可靠深度中位数；
  - 扩散网络主要学残差 \(\Delta T\)，并对深度相关项乘 `depth_conf`。
- **旋转**：正对货架时，盘面法向 / 可观测朝向优先与 **RGB 边缘、纹理** 对齐；深度只辅助消歧。

### 3.3 方案 C：RGB 通路结构升格（相对现状的具体改法）

现状问题：`concat([xyz, dino_dim]) → PointNet++`，外观仍被集合抽象吃掉。

建议升级路径（由易到难）：

1. **独立全局 RGB 条件**：`dino=global` 或 ROI 池化后的 DINO 向量，**直接 concat / 门控进 Score、Energy 头**（不只融进 PointNet）。
2. **2D cross-attention**：query = 噪声位姿编码；key/value = DINO patch token；可选再拼少量深度 token。
3. **DINO 微调策略**：优先 LoRA / 最后若干块；全量解冻对料盘数据量通常不划算。

### 3.4 监督与训练策略

与「视觉主、深度辅」对齐：

| 项 | 建议 |
|----|------|
| 旋转监督 | 只监督可观测自由度（如法向）；自转固定或降权（参见料盘边缘场景约定） |
| 平移监督 | 拆成「图像平面位置（RGB 强）」+「光轴深度（深度弱，`loss × depth_conf`）」 |
| 数据增强 | 随机丢深度 / 降采样 / 加飞点，强迫网络在差深度下仍靠 RGB 出合理候选 |
| 样本配比 | 保留一小部分「好深度」样本，专门学辅助项，避免网络完全忽略深度 |
| EnergyNet | 在「仅 RGB 可分、深度多解」的密排/对称场景仍建议训练 |

### 3.5 ScaleNet

- 料盘型号固定：继续 **写死 `size_3d`**，可不训 ScaleNet。
- 若必须回归尺寸：优先 **RGB 投影尺度 + 少量可靠深度**，避免只靠残缺点云 AABB。

### 3.6 明确不建议优先做的事

- 只加大 PointNet 或硬凑满 1024 点（空洞填噪声会更糟）。
- 一上来全量微调 DINOv2。
- 丢掉扩散改成纯回归（多峰问题仍在）。
- 完全去掉深度：\(T_z\) 仍缺度量，除非另有标定或已知层高。

## 4. 推荐落地顺序

| 阶段 | 内容 | 目的 |
|------|------|------|
| **① 诊断** | 统计有效深度点数 vs 位姿误差；看是 \(T\)（尤其 \(T_z\)）先崩，还是 \(R\) 也崩 | 确认「深度辅」假设 |
| **② 最小改动** | 点过滤 + `depth_conf` 加权 + 平移残差化 | 低成本验证方向是否成立 |
| **③ 结构改动** | RGB 独立全局条件进 Score/Energy；双分支融合 | 真正实现「视觉为主」 |
| **④ 可选增强** | DINO LoRA、2D cross-attn、深度 token 化 | 精度见顶后再上 |

## 5. 与现有代码的对应关系（便于后续实现）

| 模块 | 路径 | 改动关注点 |
|------|------|------------|
| 条件编码入口 | `networks/posenet.py` → `extract_pts_feature` / `rgb_feature` | 拆 V/D、置信度门控 |
| Score 头 | `networks/gf_algorithms/scorenet.py` | 条件 concat 增加独立 `rgb_feat` / 门控 |
| Energy 头 | `networks/gf_algorithms/energynet.py` | 与 Score 同构条件 |
| 采样回加中心 | `networks/gf_algorithms/samplers.py`（`pts_center`） | 中心估计改为 RGB+可靠深度 |
| 尺度头 | `networks/scalenet.py` | 可选；固定尺寸则跳过 |
| 配置 | `configs/`、`dino=pointwise\|global` | 新增 depth_conf、融合方式开关 |

---

## 6. 一句话结论

保留 GenPose2 的 Score / Energy 扩散推理框架；把观测条件从「**点云为主、RGB 贴附**」改为「**RGB 定姿态假设，深度按置信度校正距离与尺度**」。这与「深度很少、RGB 很稳」的料盘现场最匹配，也比单纯加深网络更对症。
