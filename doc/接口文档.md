# GenPose2 HTTP API

基于 `http_server.py` 的 REST 接口说明。服务在启动时加载 GenPose2 权重，推理时接收 RGB-D 与相机内参，内部完成 **分割 → 6D 位姿估计 → 可视化**。

- **默认地址**：`http://127.0.0.1:8002`
- **Content-Type**：`multipart/form-data`（`/infer`）
- **不需要 CAD 文件**：位姿与 3D 尺寸由网络从点云直接估计

---

## 1. 启动服务

### 依赖

```bash
pip install -r requirements.txt   # 含 fastapi、uvicorn、python-multipart、gradio 等
```

### YOLO 分割（默认）

```bash
export GENPOSE2_SCORE_CKPT=results/ckpts/ScoreNet/scorenet.pth
export GENPOSE2_ENERGY_CKPT=results/ckpts/EnergyNet/energynet.pth
export GENPOSE2_SCALE_CKPT=results/ckpts/ScaleNet/scalenet.pth

python http_server.py --host 0.0.0.0 --port 8002
```

### SAM3 文本分割

```bash
export GENPOSE2_SEG_BACKEND=sam3
export SAM6D_SAM3_ROOT=/path/to/sam3
export SAM6D_SAM3_PROMPT="white plate"   # 可选，也可在请求里传 sam3_prompt

python http_server.py --host 0.0.0.0 --port 8002 --seg-backend sam3
```

启动成功日志应包含 `GenPose2 models loaded`、`Application startup complete`。

## 3. GET /health

检查服务是否就绪，并返回当前分割后端与模型加载状态。

### 请求

```bash
curl -s http://127.0.0.1:8002/health | python -m json.tool
```

### 响应字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `status` | string | 固定 `"ok"` |
| `root_dir` | string | 仓库根目录 |
| `output_root` | string | 推理结果输出根目录（默认 `service_outputs/`） |
| `genpose_loaded` | bool | GenPose2 三网权重是否已成功加载 |
| `seg_backend` | string | 当前分割后端：`yolo` 或 `sam3` |
| `yolo_weights` | string | YOLO 权重配置路径 |
| `yolo_weights_resolved` | string | YOLO 权重绝对路径 |
| `yolo_weights_exists` | bool | 权重文件是否存在 |

当 `seg_backend` 为 `sam3` 时，额外返回：

| 字段 | 类型 | 说明 |
|------|------|------|
| `sam3_root` | string | SAM3 仓库根目录 |
| `sam3_python` | string | SAM3 子进程 Python 解释器 |
| `sam3_infer_script` | string | SAM3 推理脚本路径 |
| `sam3_prompt` | string | 环境变量中的默认 SAM3 提示词 |

### 响应示例

```json
{
  "status": "ok",
  "root_dir": "/path/to/GenPose2",
  "output_root": "/path/to/GenPose2/service_outputs",

  "sam3_infer_script": "/path/to/sam3/scripts/infer.py",
  "sam3_prompt": "white plate"
}
```

## 4. POST /infer

上传一帧 RGB、深度图与相机参数，返回 6D 位姿及可视化路径。

### 处理流程

**模式 A：自动分割（默认，不上传 mask）**

```
rgb + depth + camera
    → 分割（YOLO 或 SAM3，由 seg_backend 决定）
    → GenPose2 位姿 + 尺寸估计
    → 返回 JSON
```

**模式 B：自带 mask（上传 mask 字段）**

```
rgb + depth + camera + mask
    → 跳过分割，直接 GenPose2 推理
    → 返回 JSON（seg_backend=provided）
```

### 请求参数

`Content-Type: multipart/form-data`

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| `rgb` | 是 | file | 彩色图（PNG/JPG 等） |
| `depth` | 是 | file | 深度图，支持 `.png`（uint16）或 `.exr` |
| `camera` | 是 | file | 相机内参 JSON 文件 |
| `mask` | 否 | file | 实例 mask；上传后**跳过分割**，直接推理 |
| `sam3_prompt` | 否 | string | SAM3 文本提示词；未上传 mask 且 `seg_backend=sam3` 时生效 |

**字段名不可修改**（与 warmup 服务一致）。

#### `mask` 说明（跳过分割模式）

- 上传 `mask` 后忽略 `sam3_prompt` 与服务端分割后端，不再运行 YOLO/SAM3
- 支持 `.exr`（GenPose/cutoop 约定）或 `.png`（0/255 二值或 1..N 实例 id）
- 像素约定：`0`=背景，`1..254`=实例 id；多实例时 id 分别为 1、2、3…
- RGB、depth、mask 必须同分辨率、空间对齐

#### `sam3_prompt` 优先级

1. 请求表单字段 `sam3_prompt`（最高）
2. 环境变量 `GENPOSE2_SAM3_PROMPT` / `SAM6D_SAM3_PROMPT`
3. 内置默认值 `Plastic Reel Connected With Tape`（与 Gen6D / `configs/conf.json` → `sam3.default_prompt` 一致）

YOLO 后端会忽略 `sam3_prompt`。

#### `camera` 文件格式

支持两种 JSON 格式（二选一）：

**格式 A：warmup 风格（`cam_K` + `depth_scale`）**

```json
{
  "cam_K": [fx, 0, cx, 0, fy, cy, 0, 0, 1],
  "depth_scale": 0.001
}
```

- `cam_K`：3×3 内参矩阵，行主序 9 元素
- `depth_scale`：深度 PNG 为 uint16 毫米时通常为 `0.001`（转米）
- 使用 `cam_K` 时 **必须** 包含 `depth_scale`

**格式 B：嵌套内参**

```json
{
  "camera": {
    "intrinsics": {
      "fx": 393.12,
      "fy": 392.81,
      "cx": 322.45,
      "cy": 242.94,
      "width": 640,
      "height": 480
    }
  },
  "depth_scale": 0.001
}
```

`width` / `height` 应与 RGB 实际分辨率一致。

#### 深度图说明

- RGB、深度、分割 mask 必须 **同分辨率、空间对齐**
- 深度 PNG 为 uint16 且 `depth_scale=1.0` 时，服务会自动按 `0.001` 处理（毫米→米）
- EXR 深度由 `cutoop` 直接读取

### curl 示例

**YOLO 后端：**

```bash
curl -X POST "http://127.0.0.1:8002/infer" \
  -F "rgb=@/path/to/rgb.png" \
  -F "depth=@/path/to/depth.png" \
  -F "camera=@/path/to/camera.json" \
  --max-time 600 \
  | python -m json.tool
```

**自带 mask（跳过分割）：**

```bash
curl -X POST "http://127.0.0.1:8002/infer" \
  -F "rgb=@/path/to/rgb.png" \
  -F "depth=@/path/to/depth.png" \
  -F "camera=@/path/to/camera.json" \
  -F "mask=@/path/to/mask.exr" \
  --max-time 600 \
  | python -m json.tool
```

**SAM3 后端（带提示词）：**

```bash
curl -X POST "http://127.0.0.1:8002/infer" \
  -F "rgb=@/path/to/rgb.png" \
  -F "depth=@/path/to/depth.png" \
  -F "camera=@/path/to/camera.json" \
  -F "sam3_prompt=white plate" \
  --max-time 600 \
  | python -m json.tool
```

建议加 `--max-time 600`，避免 SAM3 子进程较慢时被 curl 超时中断。

### 成功响应（200）

#### 主实例位姿（与 warmup 对齐）

| 字段 | 类型 | 说明 |
|------|------|------|
| `score` | float | 分割置信度（最高分实例） |
| `xyz_mm` | `[x, y, z]` | 相机坐标系平移，**毫米** |
| `rotation_euler_zyx_rad` | `[rx, ry, rz]` | ZYX 欧拉角，**弧度** |
| `rotation_order` | string | 固定 `"zyx"` |
| `pose_convention` | string | 位姿约定说明 |
| `xyzrxryrz` | `[x,y,z,rx,ry,rz]` | 平移 + 欧拉角拼接 |
| `xyzrxryrz_unit` | string | 固定 `"mm_rad"` |

#### 输出路径

| 字段 | 类型 | 说明 |
|------|------|------|
| `result_dir` | string | 本次请求输出目录 |
| `detection_ism_path` | string | 分割检测结果 JSON |
| `detection_pem_path` | string | 位姿估计结果 JSON |
| `vis_ism_path` | string | 分割可视化图 |
| `vis_pem_path` | string | 位姿可视化图（坐标轴/包围盒） |
| `depth_colormap_path` | string | 深度伪彩色图（叠加 mask 目标框，0.3–1.0 m 色图） |
| `all_detections` | string | 同 `detection_pem_path` |

#### 扩展字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `seg_backend` | string | 实际使用的分割后端（`yolo` / `sam3` / `provided`） |
| `mask_source` | string | 仅 `seg_backend=provided` 时为 `"upload"` |
| `num_instances` | int | 检测到的实例数量 |
| `detections_pem` | array | 所有实例的位姿列表（见下表） |
| `sam3_prompt` | string | SAM3 实际使用的提示词（仅 sam3 后端） |
| `vis_sam3_seg_path` | string | SAM3 分割可视化（仅 sam3 且文件存在时） |

`detections_pem` 每项结构：

| 字段 | 类型 | 说明 |
|------|------|------|
| `scene_id` | int | 场景 ID |
| `image_id` | int | 图像 ID |
| `category_id` | int | 类别 ID |
| `instance_id` | int | 实例序号（从 1 开始） |
| `score` | float | 该实例分割/检测分数 |
| `t` | `[x,y,z]` | 平移，毫米 |
| `R` | `3×3` | 旋转矩阵 |
| `size_3d` | `[l,w,h]` | 3D 包围盒尺寸（米） |
| `bbox` | array | 可选，2D 框 |

#### 耗时 `timing`

| 字段 | 类型 | 说明 |
|------|------|------|
| `yolo_s` | float \| null | YOLO 分割耗时（秒） |
| `ism_s` | float \| null | SAM3 分割耗时（秒） |
| `templates_s` | float | 模板匹配耗时，本服务固定 `0.0` |
| `pose_s` | float | GenPose2 推理 + 可视化耗时 |
| `pipeline_s` | float | 分割 + 位姿总耗时 |
| `upload_s` | float | 文件上传耗时 |
| `total_s` | float | 含上传的总墙钟时间 |

### 错误响应

| HTTP 状态码 | 场景 | `detail` 示例 |
|-------------|------|---------------|
| `400` | `camera.json` 格式无效 | `invalid camera.json: camera.json with cam_K must contain depth_scale` |
| `503` | 启动时 GenPose2 未加载成功 | `GenPose2 model not loaded on server startup` |
| `500` | 推理过程异常 | 分割失败、尺寸不匹配、无有效位姿等 |

## 5. 服务端环境变量

### GenPose2 权重

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `GENPOSE2_SCORE_CKPT` | `results/ckpts/ScoreNet/scorenet.pth` | ScoreNet 权重 |
| `GENPOSE2_ENERGY_CKPT` | `results/ckpts/EnergyNet/energynet.pth` | EnergyNet 权重 |
| `GENPOSE2_SCALE_CKPT` | `results/ckpts/ScaleNet/scalenet.pth` | ScaleNet 权重 |
| `GENPOSE2_OUTPUT_ROOT` | `service_outputs` | 推理输出根目录 |

### 分割后端

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `GENPOSE2_SEG_BACKEND` | `yolo` | 分割后端：`yolo` / `sam3` |

### YOLO 参数

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `GENPOSE2_YOLO_WEIGHTS` | `segment/yolo_seg.pt` | YOLO 分割权重 |
| `GENPOSE2_YOLO_CONF` | `0.25` | 置信度阈值 |
| `GENPOSE2_YOLO_IMGSZ` | `640` | 推理输入尺寸 |
| `GENPOSE2_YOLO_CLASS_ID` | `0` | 类别 ID；`-1` 表示不限类别 |
| `GENPOSE2_YOLO_MAX_INSTANCES` | `1` | 最多保留实例数 |

### SAM3 参数

| 变量 | 说明 |
|------|------|
| `GENPOSE2_SAM3_PROMPT` / `SAM6D_SAM3_PROMPT` | 默认文本提示词 |
| `GENPOSE2_SAM3_ROOT` / `SAM6D_SAM3_ROOT` | SAM3 仓库根目录 |
| `GENPOSE2_SAM3_PYTHON` / `SAM6D_SAM3_PYTHON` | SAM3 子进程 Python |
| `GENPOSE2_SAM3_INFER_SCRIPT` / `SAM6D_SAM3_INFER_SCRIPT` | SAM3 推理脚本 |
| `GENPOSE2_SAM3_THRESHOLD` / `SAM6D_SAM3_THRESHOLD` | 检测阈值（默认 0.41） |
| `GENPOSE2_SAM3_MASK_THRESHOLD` / `SAM6D_SAM3_MASK_THRESHOLD` | mask 阈值（默认 0.50） |
| `GENPOSE2_SAM3_MAX_INSTANCES` | 最多保留实例数；`0` 表示保留全部 |
| `GENPOSE2_SAM3_CHECKPOINT` / `SAM6D_SAM3_CHECKPOINT` | 可选，SAM3 checkpoint 路径 |

## 6. 输出目录结构

每次 `/infer` 请求在 `service_outputs/<timestamp>_<uuid>/` 下生成：

```
service_outputs/20260610_172229_ab12a379/
├── inputs/
│   ├── rgb.png
│   ├── depth.png
│   └── camera.json
└── sam6d_results/
    ├── mask.exr
    ├── detection_ism.json
    ├── detection_pem.json
    ├── vis_ism.png
    ├── vis_pem.png
    ├── depth_colormap.png   # 深度伪彩色，接口字段 depth_colormap_path
    └── vis_sam3_seg.png      # 仅 SAM3 后端
```

---

## 7. 注意事项

1. **并发**：推理串行执行（全局锁），同时多个请求会排队等待。
2. **无需 CAD**：本 API 不要求上传物体 CAD/模板模型。
3. **分割质量**：YOLO 需能检出目标类别；SAM3 需合适的 `sam3_prompt`。
4. **OpenAPI**：服务启动后可访问 `http://127.0.0.1:8002/docs` 查看 Swagger 交互文档。
